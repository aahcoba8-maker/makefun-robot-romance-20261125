# Robot Romance: One-Line Pickup Lines for AI — make.fun entry

One joke pickup line, aimed at a robot or an AI, under 200 characters:

> I ran a million simulations, and in every single one, you said yes.

`main.py` writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to the script directory), with a self-gate assert matching the
kit's 1–200 character, single-line, non-whitespace rule.
